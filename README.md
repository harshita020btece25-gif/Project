## Amazon clone
# About the Project

A simple frontend clone of the Amazon homepage built using HTML, CSS and JavaScript. This project recreates the look and layout of Amazon's landing page for learning and practice purposes. This project was developed as part of our web development learning journey. The goal was to strengthen our understanding of **HTML**,**CSS** and **JavaScript**.

Working together allowed us to practice collaborative development, improve our problem-solving skills, and gain hands-on experience in building responsive and visually appealing user interfaces. Through this project, we explored concepts such as page layout, Flexbox, styling, component organization, and basic JavaScript functionality while following a real-world website design.

Although this project recreates only the homepage of Amazon, it served as a valuable learning experience and helped us build a strong foundation in frontend web development.

# Features
Responsive navigation bar   
Search bar with category selector    
Hero banner section    
Product category cards     
Footer with multiple sections    
Clean and organized layout using CSS
Interactive hero image carousel using JavaScript

HTML5

JavaScript
